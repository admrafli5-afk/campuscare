- ramah mahasiswa
- bersih
- hijau
- paperless
- profesional
- ringan digunakan

# Design Rules

- gunakan whitespace cukup
- hindari warna terlalu mencolok
- gunakan icon sederhana
- mobile dan web wajib konsisten
- gunakan card putih
- gunakan layout bersih

# Responsive Rules

## Mobile

Width utama:
360px - 430px

## Web

Minimum:
1280px

---

# Layout Rules

- gunakan padding 16-24px
- gunakan spacing konsisten
- jangan gunakan terlalu banyak warna
- maksimal 2 warna utama
- hindari full gradient berlebihan

---

# Animation Rules

- gunakan animation lembut
- maksimal 300ms
- jangan gunakan animasi berlebihan

---

# Icon Rules

Gunakan:

- HeroIcons
  atau
- Lucide Icons
